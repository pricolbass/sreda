# 11: Пользователь восстанавливает пароль через администратора

**What to build:** администратор создаёт в кабинете одноразовую ссылку восстановления и лично передаёт её пользователю. Пользователь самостоятельно задаёт новый пароль. Аварийное восстановление администратора выполняется вручную на маме.

**Blocked by:** 02 — Администратор приглашает пользователя.

Status: ready-for-agent

- [ ] Администратор выбирает пользователя, создаёт ссылку и видит срок её действия. Отправка почты не требуется.
- [ ] По действующей ссылке пользователь самостоятельно задаёт новый пароль; администратор не получает этот пароль.
- [ ] Определены срок действия ссылки, поведение при выдаче следующей ссылки и политика существующих сессий после смены пароля; поведение явно проверено.
- [ ] Использованная и просроченная ссылка отвергается. Конкурентное применение одной ссылки не выполняет несколько смен пароля.
- [ ] После восстановления новый пароль работает, прежний не работает. Восстановление пароля само по себе не меняет права пользователя или состояние его ресурсов.
- [ ] Обычный пользователь не может выдавать ссылки восстановления другим людям или подменить целевого пользователя.
- [ ] Описан и проверен ручной способ аварийного восстановления администратора на маме без публичного механизма восстановления администратора.
