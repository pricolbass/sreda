# 06: Пользователь удаляет публикацию и освобождает машину

**What to build:** пользователь окончательно удаляет публикацию с подтверждением потери поддомена. После удаления всех связанных публикаций он может удалить машину; кабинет объясняет, какие публикации пока препятствуют этому.

**Blocked by:** 05 — Пользователь отключает и повторно включает публикацию.

Status: ready-for-agent

- [ ] Удаление требует явного подтверждения, что имя будет освобождено и может быть занято другим пользователем.
- [ ] Сначала подтверждается очистка доступа и старого маршрута, затем освобождается поддомен. Ошибка или таймаут оставляют имя зарезервированным и показывают незавершённое удаление.
- [ ] Удалённая публикация больше не принимается агентом; повторные и устаревшие команды не восстанавливают её маршрут.
- [ ] Другой пользователь может занять освобождённое имя без попадания запросов к прежнему приложению.
- [ ] Общие wildcard DNS и сертификат сохраняются, остальные публикации работают.
- [ ] Машину нельзя удалить, пока существуют связанные публикации, включая отключённые. Кабинет перечисляет препятствия; каскадного удаления нет.
- [ ] После удаления последней публикации машину можно удалить с прекращением её подключения и отзывом учётных данных; незавершённая очистка не отображается как успешное удаление.
- [ ] Владение проверяется сервером. Проверены ошибки очистки, повторные запросы и конкурентные создание публикации, удаление машины и повторное занятие поддомена.
