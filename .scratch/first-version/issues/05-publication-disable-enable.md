# 05: Пользователь отключает и повторно включает публикацию

**What to build:** пользователь закрывает внешний доступ к публикации, сохраняя её поддомен и настройки, а затем явно включает её по прежнему адресу. Приложение на машине продолжает работать независимо от публикации.

**Blocked by:** 04 — Пользователь публикует локальное приложение по HTTPS.

Status: ready-for-agent

- [ ] Отключение и включение доступны владельцу в кабинете и проверяют полномочия на сервере.
- [ ] Во время отключения показывается «Отключается»; «Отключена» означает подтверждённое закрытие внешнего доступа. Ошибка и отсутствие подтверждения отображаются явно.
- [ ] Отключение закрывает новые и уже установленные соединения публикации; закрытие контролируется на маме и не зависит только от ответа агента.
- [ ] Недоступность агента не мешает закрыть доступ через шлюз; ошибка изменения маршрута или таймаут не считаются успехом.
- [ ] Поддомен и настройки остаются закреплены; локальное приложение не останавливается. Явное включение возвращает прежний внешний адрес без повторного подключения машины.
- [ ] Повторные запросы и устаревшие команды не отменяют более позднее намеренное отключение. Состояние операции сохраняется для дальнейшего восстановления после перезапуска.
- [ ] Проверены отключение при активном соединении, недоступном агенте и ошибке применения, повторное включение и сохранение работы другой публикации.
