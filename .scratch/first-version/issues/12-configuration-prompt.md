# 12: Пользователь копирует промпт для настройки приложения

**What to build:** в кабинете пользователь копирует полезный текст для настройки своего приложения, составленный из шаблона и актуальных параметров подключения или публикации. Он может добавить описание приложения и документацию и использовать текст во внешней нейросети.

**Blocked by:** 07 — Пользователь публикует приложение через ручной WireGuard-конфиг.

Status: resolved

- [x] Кнопка «Скопировать промпт для настройки» доступна в подходящем контексте подключения или публикации и сообщает о результате копирования.
- [x] Текст отражает выбранный способ подключения, параметры машины и публикации, HTTPS-адрес и необходимые действия пользователя. Для ручного режима явно учитывается самостоятельное обеспечение доступности приложения через туннель.
- [x] Пользователь получает параметры только собственных ресурсов; изменение выбранной публикации отражается в новом тексте.
- [x] В текст не попадают пароли, приватные ключи, одноразовые коды и ссылки с секретными токенами. Проверены примеры для обоих способов подключения.
- [x] Формирование представляет собой подстановку данных в шаблон: нет вызова модели, передачи данных во внешний ИИ API или исполнения команд через агент.
- [x] Примеры полученного текста проверены на полезность для настройки произвольного веб-приложения; специальная интеграция с конкретным продуктом не требуется.


## Answer

Реализованы owner-only страницы промпта для машины и выбранной публикации,
редактируемый текст, копирование с подтверждением и ручной fallback при отказе
браузера. Отдельный модуль `internal/setupprompt` работает с безопасным DTO
машины и актуальными параметрами публикации; SQL остаётся в машинном модуле.
Вызовов моделей и выполнения команд нет.

Проверено локально через согласованный HTTP seam и реальную SQLite:
агент/ручной WireGuard, два разных адреса публикации, чужой пользователь
и администратор, анонимный запрос, отсутствие действующих секретов.
Первая HTTP-проверка до реализации завершилась 404; после реализации проходит.
Примеры и ограничения: [инструкция](../../../docs/configuration-prompt.md).
Реальное поведение разрешений clipboard в браузере и Debian/WireGuard
не проверялось; данная задача не требует внешней модели или стенда.
