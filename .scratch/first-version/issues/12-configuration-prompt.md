# 12: Пользователь копирует промпт для настройки приложения

**What to build:** в кабинете пользователь копирует полезный текст для настройки своего приложения, составленный из шаблона и актуальных параметров подключения или публикации. Он может добавить описание приложения и документацию и использовать текст во внешней нейросети.

**Blocked by:** 07 — Пользователь публикует приложение через ручной WireGuard-конфиг.

Status: ready-for-agent

- [ ] Кнопка «Скопировать промпт для настройки» доступна в подходящем контексте подключения или публикации и сообщает о результате копирования.
- [ ] Текст отражает выбранный способ подключения, параметры машины и публикации, HTTPS-адрес и необходимые действия пользователя. Для ручного режима явно учитывается самостоятельное обеспечение доступности приложения через туннель.
- [ ] Пользователь получает параметры только собственных ресурсов; изменение выбранной публикации отражается в новом тексте.
- [ ] В текст не попадают пароли, приватные ключи, одноразовые коды и ссылки с секретными токенами. Проверены примеры для обоих способов подключения.
- [ ] Формирование представляет собой подстановку данных в шаблон: нет вызова модели, передачи данных во внешний ИИ API или исполнения команд через агент.
- [ ] Примеры полученного текста проверены на полезность для настройки произвольного веб-приложения; специальная интеграция с конкретным продуктом не требуется.
