# Модуль машин

`internal/machine.Manager` отвечает за владение машиной, выдачу и применение
кода, управляющие учётные данные, выделение адреса и жизненный цикл подключения.
Он не знает HTTP, cookies, JSON или HTML. `sqlite.go` содержит запросы и
транзакционные операции; политика и координация WireGuard находятся в
`manager.go`. Реальный сетевой интерфейс — `tunnel.Gateway`: его реализуют
Unix-клиент Linux helper и адаптер сетевого стенда локальных HTTP-проверок.

`internal/agentcontrol.Controller` соединяет проверку учётных данных машины
с подтверждением и получением карты публикаций. Узкий интерфейс `Routes`
принадлежит этому потребителю. Модуль публикаций удовлетворяет ему без
зависимости от HTTP-обработчиков или от внутреннего устройства машин.

`cabinet/machine_http.go` получает поля формы/JSON и текущего пользователя,
вызывает прикладную операцию и переводит результат в HTML/JSON и HTTP-статус.
Он не выполняет SQL, не распределяет адреса и не применяет peers. `App`
собирает модули при запуске; старые CLI/программные точки входа делегируют
операции модулю машин для сохранения совместимости.

Проверки поведения остаются на ранее согласованных интерфейсах CLI и HTTP
с настоящей SQLite. После переноса кода прежние сценарии машин/агента
прошли с race detector без изменения тестов. Локальный результат не означает
проверку реального kernel WireGuard или Debian LXC.

После восстановления peers публикации повторяют пропущенное подтверждение
ручного подключения. Кандидат читается из сохранённого состояния; транзакция
подтверждения заново проверяет версию машины и доступа владельца, включённое
состояние и отсутствие незавершённых операций. Выключенные и удаляемые
публикации не включаются. Сбой после применения peer и использования кода
больше не требует повторного подключения машины.

Фоновое восстановление проверяет обе версии снимка и текущее желаемое
состояние подключения перед резервированием операции. Устаревший снимок
выключенной машины не отменяет более новое включение владельца; то же
ограничение действует для включения и незавершённого переподключения.
