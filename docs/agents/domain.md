# Документация предметной области

Используется single-context: единый словарь и общие архитектурные решения
для всего репозитория.

## Перед исследованием кодовой базы

- Прочитай `GLOSSARY.md` в корне репозитория.
- В `docs/adr/` прочитай решения, относящиеся к исследуемой области.

Если этих файлов или каталогов нет, продолжай работу без замечаний
об их отсутствии и без предложения заранее создавать пустые документы.
Навык `/domain-modeling` создаёт их по мере определения терминов
и принятия решений.

## Расположение

- `GLOSSARY.md` — словарь предметной области.
- `docs/adr/NNNN-<slug>.md` — архитектурные решения,
  например `docs/adr/0001-storage-model.md`.

## Терминология

В задачах, предложениях изменений, гипотезах и названиях тестов используй
термины из `GLOSSARY.md`.

Если нужного понятия нет в словаре, проверь, соответствует ли оно языку
проекта. Если это реальный пробел, отметь его для `/domain-modeling`.

## Конфликты с архитектурными решениями

Если предложение противоречит существующему ADR, явно укажи документ,
суть противоречия и причину, по которой решение стоит пересмотреть.
