# Метки задач

Для triage используются пять стандартных ролей.
В локальных Markdown-задачах метка записывается в строку `Status:`.

| Роль навыка | Значение в трекере | Значение |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Требуется первичная оценка задачи |
| `needs-info` | `needs-info` | Требуется дополнительная информация от автора |
| `ready-for-agent` | `ready-for-agent` | Задача полностью описана и готова к автономной работе агента |
| `ready-for-human` | `ready-for-human` | Требуется реализация человеком |
| `wontfix` | `wontfix` | Задача не будет выполняться |

Когда навык просит применить роль, используй соответствующее значение
из столбца «Значение в трекере».
