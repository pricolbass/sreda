## Agent skills

### Issue tracker

Задачи и спецификации хранятся локально в `.scratch/`.
Перед созданием, чтением или обновлением задач прочитай
`docs/agents/issue-tracker.md`.

### Triage labels

Используются пять стандартных меток.
Перед назначением статуса задачи прочитай `docs/agents/triage-labels.md`.

### Domain docs

Используется single-context: `GLOSSARY.md` и `docs/adr/` в корне репозитория.
Перед исследованием кодовой базы прочитай `docs/agents/domain.md`.
